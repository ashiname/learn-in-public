<h1>Ortofonia e Ortografia</h1>

# Ortofonia
É o ramo da gramática que trata das pronúncias certas das palavras. Som correto, orientado a partir da norma padrão

## Ortoépia
Pronúncia adequada das palavras. (Ritmo, entonação...)

| Correta     | Incorreta    |
| ----------- | ------------ |
| LAGARTO     | LARGARTO     |
| SOBRANCELHA | SOMBRANCELHA |
| IOGURTE     | IORGURTE     |

## Prosódia
Acentuação adequada da sílaba tônica de cada palavra (Norma padrão).

| Correta  | Incorreta |
| -------- | --------- |
| graTUIto | gratuIto  |
| ruIM     | RUim      |
| noBEL    | NObel     |

Errar a sílaba tônica = silabada

Obs: Há palavras com mais de uma pronúncia correta! <br>
XÉROX / XEROX <br>
ORTOÉPIA / ORTOEPIA
