# Foot notes | Notas de rodapé
As notas de rodapé são utilizadas para citar a referência. Referência serve para citar o a origem da qual você está tirando aquela informação. <br>
Citações muito importante para dar solidez ao seu texto.


```Markdown
Coisa tal[^1]

[^1]: referência
```
