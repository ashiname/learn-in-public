You can actually make inverted ordered lists (`ol`) using the property `reversed` inside the first `ol` brackets.


Code:

```
<ol reversed>  
<li>new item</li>  
<li>previous item</li>  
<li>old item</li>  
</ol>
```

Result:

<ol reversed>  
<li>new item</li>  
<li>previous item</li>  
<li>old item</li>  
</ol>
